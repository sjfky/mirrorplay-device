mirrorplay

H.264 into a browser · touch back to the source reading the relay…

A relay built to the shape of OpenXPlay: its wire format, its session model, its receiver page. What flows through it is a synthetic scene or a browser tab rather than CarPlay, because CarPlay needs an Apple-issued accessory (MFi) identity that no build of either project contains.

Head unit

The car's browser. Decodes the projection with WebCodecs and sends touch and keys back.

/receiver

Device

The phone's stand-in. Encodes its own screen or camera into the projection.

/input

Relay

Session, per-receiver statistics, touch read-out, scene buttons, event trace.

/admin

Self-check

Open this in the car browser first: it decodes a frame from this relay and says whether it worked.

/check

iPhone, without a Mac

In Safari: Share → Add to Home Screen. The shortcut opens already paired, because the relay generates the manifest and puts its token in the icon's URL — the reason this is generated rather than written by hand.

This is the stand-in for an .ipa when nothing can sign one. A web page gets the camera, never the phone's own display: pictures that leave the app you are in still need the native target, and that needs a Mac.
